## ✨ Features

- 🎯 **Single-page + multi-page structure** — Main landing page with anchored sections and separate detail pages
- 📱 **Fully responsive design** — Mobile-first, works on all screen sizes
- 🧭 **Interactive navigation** — Dropdown menus for Experience and Certifications
- 🖼️ **Portfolio lightbox modal** — Click any project/activity to view it in a fullscreen modal with prev/next navigation & keyboard support (`Esc`, `←`, `→`)
- 🗂️ **Filter tabs** — "ALL" / "LATEST" filters for activities, and category filters for certifications
- 🎞️ **Scroll animations** — Projects, skills, and experience items fade in on scroll using Intersection Observer
- 🧠 **Smart active-link highlighting** — Automatically highlights the current section in the nav
- 🎭 **Auto-hiding header** — Header hides on downward scroll and reappears on upward scroll
- 🌗 **Smooth scrolling** — Smooth in-page navigation between sections
- 🧩 **Modular pages** — Projects, Experience, Portfolio, Course, Tech & Non-Tech, Certifications, and Contact pages
- 🔗 **Social links** — LinkedIn, GitHub, WhatsApp, and Email

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)

### Run Locally

Since this is a static website, there's no build step required.

1. **Clone the repository:**

   ```bash
   git clone https://github.com/mohanramasamy2005-eng/portfolio.git
   ```

2. **Navigate to the project folder:**

   ```bash
   cd Portfolio
   ```

3. **Open the site:**
   - Simply double-click on `index.html`, **or**
   - Run a local server:
     ```bash
     # Using Python
     python -m http.server 5500
     # Then visit http://localhost:5500
     ```
